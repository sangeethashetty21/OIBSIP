# Tribute Page — Dr. A. P. J. Abdul Kalam

A responsive tribute page built with HTML5, CSS3 and a little vanilla JavaScript.

## Checklist coverage
- Page title with the subject's name and a one-line tagline
- Prominent portrait (`kalam.jpg`; a monogram shows if the image is missing)
- Four paragraphs of original biography text
- Ordered-list timeline of key achievements
- Distinct, styled quote block
- Multiple background colours (navy, cream, teal) and two fonts (Fraunces serif headings, Work Sans body)
- Responsive layout (desktop, tablet, mobile)

## Extras
Sticky navigation with smooth scroll, key-facts cards, "What he left behind" cards, scroll-reveal animation, back-to-top button, reduced-motion support.

## Before you submit
1. Download a public-domain portrait from Wikimedia Commons and save it here as `kalam.jpg`.
2. Replace `[Your Name]` in the footer of `index.html`.
3. Add screenshots in a `screenshots/` folder.

## Run
Open `index.html` in a browser.
