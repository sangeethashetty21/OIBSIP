# Calculator

A "Mini Calculator" with a welcome screen that opens into a browser-based calculator, built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Display for current input and result
- Digits 0-9 and decimal point
- Operators: + − × ÷, equals, clear (C), backspace (⌫)
- Division by zero shows an error message instead of crashing
- Operator chaining without a reset (evaluates left to right: `5 + 3 × 2 = 16`)
- CSS Grid button layout
- All buttons use `addEventListener` (no inline `onclick`)
- No `eval()`; logic uses variables and a `switch` statement
- Keyboard support
- Welcome screen ("Welcome to Mini Calculator") with animated background and an Open Calculator button; back button returns to it

## Run
Open `index.html` in a browser.
