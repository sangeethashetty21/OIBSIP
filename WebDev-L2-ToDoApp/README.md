# To-Do Web App

Task manager built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Add tasks with input + "Add Task" button
- New tasks appear in **Pending Tasks**
- Tick the checkbox to move a task to **Completed Tasks** (untick to move back)
- Inline **Edit** (Enter to save, Esc to cancel) and permanent **Delete**
- "X pending" / "Y completed" counters above each list
- Bonus: added/completed timestamps and `localStorage` persistence
- Friendly empty-state messages
- Progress bar, date header and "Clear completed" button

## Run
Open `index.html` in a browser.
